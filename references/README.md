# Reference Books

A curated collection of essential books for system programming under Linux. Organized by category for easy navigation and learning.

---

## Programming

Books covering system programming, libraries, and threading fundamentals.

- **[Libc Manual](./Programming/Libc_Manual.pdf)**  
  _GNU C Library reference_  
  **Used for:** Reference when working with standard C functions.  
  **Knowledge gained:** Complete understanding of C standard library functions and their usage.

- **[Programming with POSIX Threads](./Programming/Programming_with_POSIX_Threads.pdf)**  
  _David R. Butenhof_  
  All about threads.  
  **Used for:** Building concurrent applications.  
  **Knowledge gained:** Thread creation, synchronization, and parallel programming techniques.

- **[Linux System Programming (2nd Edition)](./Programming/Linux_System_Programming_2nd_Edition.pdf)**  
  _Robert Love_  
  Deep dive into Linux system calls.  
  **Used for:** Writing efficient Linux system-level programs.  
  **Knowledge gained:** Advanced file operations, memory management, and Linux-specific APIs.

- **[Advanced Programming in the UNIX Environment (3rd Edition)](./Programming/Advanced_Programming_in_the_UNIX_Environment_3rd_Edition.pdf)**  
  _W. Richard Stevens & Stephen A. Rago_  
  Classic guide to UNIX programming.  
  **Used for:** Developing robust UNIX/Linux applications with proper system calls.  
  **Knowledge gained:** Process management, file I/O, signals, and interprocess communication.

- **[The Linux Programming Interface](./Programming/The_Linux_Programming_Interface.pdf)**  
  _Michael Kerrisk_  
  The go-to book for Linux APIs.  
  **Used for:** Comprehensive reference for Linux system programming.  
  **Knowledge gained:** System calls, library functions, and low-level Linux programming concepts.

## Operating Systems

OS theory and Linux kernel development resources.

- **[Operating Systems: Design and Implementation (3rd Edition)](./Operating_Systems/Andrew_S_Tanenbaum_Operating_Systems_Design_and_Implementation.pdf)**  
  _Andrew S. Tanenbaum & Albert S. Woodhull_  
  Classic OS book with MINIX.  
  **Used for:** Understanding OS principles through practical implementation.  
  **Knowledge gained:** Process scheduling, memory management, file systems, and OS architecture.

- **[Linux Kernel Development (3rd Edition)](./Operating_Systems/Linux_Kernel_Development_3rd_Edition.pdf)**  
  _Robert Love_  
  Inside the Linux kernel.  
  **Used for:** Kernel development and understanding Linux internals.  
  **Knowledge gained:** Kernel subsystems, device drivers, and kernel programming techniques.

## Networking

Network programming and socket development guides.

- **[TCP/IP Sockets in C (2nd Edition)](./Networking/TCP_IP_Sockets_in_C_Second_Edition.pdf)**  
  _Michael J. Donahoo & Kenneth L. Calvert_  
  Socket programming in C.  
  **Used for:** Building network client/server applications.  
  **Knowledge gained:** TCP/IP protocols, socket API, and network programming patterns.

- **[UNIX Network Programming: The Sockets Networking API (3rd Edition)](./Networking/Unix_Network_Programming_The_Sockets_Networking_API.pdf)**  
  _W. Richard Stevens et al._  
  The sockets bible.  
  **Used for:** Advanced network programming and protocol implementation.  
  **Knowledge gained:** Socket options, advanced I/O, and network protocol design.
