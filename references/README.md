# Reference Books

A curated collection of essential books for system programming under Linux. Organized by category for easy navigation and learning.

**📗 Beginner** | **📙 Intermediate** | **📕 Advanced**

> Books are numbered (01, 02, etc.) in order of difficulty within each category, from easiest to most advanced.

---

## Programming

Books covering system programming, libraries, and threading fundamentals.

- **[01 - Libc Manual](./Programming/01_Libc_Manual.pdf)** 📗  
  _GNU C Library reference_  
  **Used for:** Reference when working with standard C functions.  
  **Knowledge gained:** Complete understanding of C standard library functions and their usage.

- **[02 - Programming with POSIX Threads](./Programming/02_Programming_with_POSIX_Threads.pdf)** 📙  
  _David R. Butenhof_  
  All about threads.  
  **Used for:** Building concurrent applications.  
  **Knowledge gained:** Thread creation, synchronization, and parallel programming techniques.

- **[03 - Linux System Programming (2nd Edition)](./Programming/03_Linux_System_Programming_2nd_Edition.pdf)** 📙  
  _Robert Love_  
  Deep dive into Linux system calls.  
  **Used for:** Writing efficient Linux system-level programs.  
  **Knowledge gained:** Advanced file operations, memory management, and Linux-specific APIs.

- **[04 - Advanced Programming in the UNIX Environment (3rd Edition)](./Programming/04_Advanced_Programming_in_the_UNIX_Environment_3rd_Edition.pdf)** 📕  
  _W. Richard Stevens & Stephen A. Rago_  
  Classic guide to UNIX programming.  
  **Used for:** Developing robust UNIX/Linux applications with proper system calls.  
  **Knowledge gained:** Process management, file I/O, signals, and interprocess communication.

- **[05 - The Linux Programming Interface](./Programming/05_The_Linux_Programming_Interface.pdf)** 📕  
  _Michael Kerrisk_  
  The go-to book for Linux APIs.  
  **Used for:** Comprehensive reference for Linux system programming.  
  **Knowledge gained:** System calls, library functions, and low-level Linux programming concepts.
